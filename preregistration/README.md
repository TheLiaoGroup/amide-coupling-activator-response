# Pre-registration record

SI Note 2 of the manuscript ("Pre-registration record and the full descriptor contest") describes
four frozen files. All four are included here:

| SI's label | file here |
|---|---|
| Stage 1 pre-registration | `Stage1_preregistration.md` |
| Amendment 1 (response specification) | `Stage1_and_Amendment1.md` |
| Stage 2 pre-registration | `Stage2_preregistration.md` |
| Stage 3 pre-registration | `Stage3_preregistration.md` |

**Stage 1 and Amendment 1 are two states of the same working document, not two separate files.**
`notes/PREREGISTRATION_acylation_stage1.md` was frozen at Stage 1, then had a "# AMENDMENT 1"
section appended to the end of the same file after the primary scoring showed the pre-registered
response measured the wrong thing (logged 2026-08-31, before the amended response was computed) -
the file was not copied to a new name first. `Stage1_preregistration.md` here is the exact
byte-for-byte prefix of that file ending right where the original document ended;
`Stage1_and_Amendment1.md` is the file in its current, full state (matching the Amendment 1 row).
Reading Stage1_preregistration.md alongside the "# AMENDMENT 1" section of
Stage1_and_Amendment1.md gives the same information as two separately frozen files would.
